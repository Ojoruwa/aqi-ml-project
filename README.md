# 🌍 AQI Intelligence System

Real-time Air Quality Monitoring and Forecasting Platform powered by Machine Learning.

---

## 🚀 Features

- 🌍 Live AQI Monitoring
- 📈 Real-time Trend Visualization
- 🧠 ML-Based AQI Prediction
- 🔮 Forecasting System
- 🗺 AQI Heatmap
- 🚨 Air Quality Alert System
- ⚡ Auto-Updating Dashboard
- ☁ Cloud Deployment

---

## 🧠 Machine Learning

This system uses a trained ML model to predict Air Quality Index levels using:

- Temperature
- Humidity
- Pressure
- Wind Speed
- PM2.5
- PM10
- NO2

---

## 🛠 Tech Stack

- Python
- Streamlit
- Scikit-Learn
- TensorFlow
- Plotly
- PyDeck
- OpenWeather API
